# api/lib/

## Responsibility

Shared PHP libraries required by endpoints and the cron scripts: `Mailer` (SMTP email), `EmailTemplate` (branded email layout, one theme per enterprise in `email-themes.php`), `Gemini` (Google Gemini REST client), `GoogleDrive` (read-only Drive client), `IndexNow` (search-engine change pings), `CrawlerPage` + `JobPages` (crawler HTML pages) and `Ats` (applicant screening). Not web-accessible: `.htaccess` is `Require all denied`.

## Design

- `DataFixes.php`: `DATA_FIXES` (name => function) + `runDataFixes($pdo, $log)`: one-off data corrections production needs when a release ships, each run once per database (recorded in `migration_seeds`, inside a transaction) and leaving staff-written values alone. Run by `cron/data-fixes.php` on deploy and by `migrate.php`. `fix:virtual-office-2026-plans` gives the Virtual Office plans their 2026 names, photos and inclusions, matching each plan by its 2026 or previous title. `fix:manila-timestamps` moves MySQL-filled stamps (`SERVER_TZ_COLUMNS`: chat, inquiries, applicants) written in the server's zone (UTC on Hostinger) before `db.php` pinned `+08:00`; a no-op where the server is already +08:00. `fix:blog-cover-webp` points blog covers still holding a seeded PNG/JPG original (`BLOG_COVER_SEED_ORIGINALS`) at the WebP copy beside it, only when that file is deployed. `fix:chat-status-updated-index` adds the `chat_sessions` index `idx_chat_status_updated (status, updated_at)` (closed-chat paging, idle-expiry scan) when missing.
- `Profanity.php`: `censorProfanity($text)` masks English and Filipino swear words (`f***`, first letter kept), whole words only, case-insensitive, leetspeak and stretched letters. Applied to visitor messages in `chat/message.php` (before storage, Gemini and the handoff email) and admin replies in `admin/chat.php`.
- `JobSchema.php`: `JOB_SCHEMA_COLUMNS` + `jobSchemaEnsure($pdo)` (idempotent `ALTER TABLE ... ADD COLUMN`, once per request) for columns added after launch (the public `careers.php` calls it only when its query hits a missing column); `schema.sql` carries the same for fresh installs.
- `CrawlerPage.php`: shared by the crawler HTML pages `properties-page.php`, `careers-page.php` and `blog-page.php` (no requires). `esc()`, `metaTag()`, `headTags($title, $description, ?$url, ?$image, $graph)` (the head `components/Seo.tsx` renders: null `$url` = `noindex, follow` without canonical/`og:url`, null `$image` = the default OG image with its size, empty `$graph` = no JSON-LD) and `sendPage($status, $head, $body)` (the docroot `index.html` with its `<title>` and `data-rh` tags swapped for `$head`, `#root` hidden and `$body` in `#prerender`; then exits). `COMPANIES` (slug => [name, logo]) is the one PHP map of company names (`src/data/enterprises.js`) and logos (`ENTERPRISE_META` in `components/Seo.tsx`); the group itself is named by each caller, and `email-themes.php` keeps its longer brand names.
- `JobPages.php` (requires `CrawlerPage.php`): `jobPageUrl()`, `jobOpening($row)`, `jobHiringOrganization($slug)` and `jobPageSeo($job)`, the job page head + `JobPosting` JSON-LD that `src/lib/jobSeo.ts` also builds (`tests/unit/job-seo.test.mjs` compares both). Used by `careers-page.php` and `jobs-sitemap.php`.
- `Validation.php`: `validationNameError()`, `validationPhoneError()`, `validationTextError()`, `validationUrlError()`; same rules and messages as `src/lib/formValidation.ts` (a unit test compares both).
- `ChatExpiry.php`: `expireIdleChats($pdo)` closes every non-closed `chat_sessions` row idle for `CHAT_IDLE_HOURS` (24) and adds a bot note to each thread, in one transaction. Called lazily from `admin/chat.php` (inbox list and `?summary=1` counts) and `chat/start.php` (restoring a token); `start.php` never restores a closed session, so a returning visitor gets a fresh chat.
- `Mailer.php`: no external packages. The constructor captures `SMTP_HOST/PORT/USER/PASS/SECURE`, `MAIL_FROM_EMAIL`, `MAIL_FROM_NAME` from `config.php`. `send($to, $subject, $htmlBody, $replyToEmail, $replyToName, $attachments)` uses `sendViaSmtp()` (PHP sockets: implicit SSL on 465 or STARTTLS, AUTH LOGIN) when credentials are set. Every message is multipart/alternative (plain text from `htmlToText()` + HTML); inline cid images go in multipart/related, files in multipart/mixed. It and falls back to `sendViaNativeMail()` (`mail()`). No persistence or retry.
- `Gemini.php`: `geminiEnabled()` (non-empty `GEMINI_API_KEY`) and `geminiGenerate($system, $parts, $schema, $history, $timeout)`, a cURL call to `v1beta/models/{GEMINI_MODEL}:generateContent` (default `gemini-3.6-flash`, key in `x-goog-api-key` header). It sends a system instruction, prior user/model turns, temperature 0.3, and `BLOCK_LOW_AND_ABOVE` safety settings for harassment, hate, sexual, and dangerous content. With a schema it requests JSON output and returns the decoded array. Returns `null` on any failure so callers fall back to non-AI behaviour.
- `IndexNow.php` (requires `Listings.php` for `REALTY_ORIGIN`): `INDEXNOW_KEY` (public by protocol design; verified at `public/<key>.txt`, served on the Realty host). `indexNowChangedRefs($old, $new)` (pure) returns the sorted refs added, removed, or with a changed title/deal/area/size/price/terms/photos; `indexNowPayload($urls)` builds the body (Realty host, key, keyLocation, ≤ 10,000 unique URLs); `indexNowSubmit($urls)` POSTs it to `api.indexnow.org` (5s connect, 10s total) and returns null on HTTP 200/202, else a short error. Bing shares IndexNow pings with ChatGPT search, Copilot, DuckDuckGo and Yahoo; Yandex too.
- `EmailTemplate.php` + `email-themes.php`: `emailTheme($slug)` returns the enterprise's tokens (colours, fonts, radii, logo) taken from what each enterprise website renders. `emailRender($t, $o)` builds a table-based, inline-styled email (eyebrow/badge, title, rows, quote, sections, buttons, footer). The brand header is one PNG drawn with GD (`emailHeaderAttachment()`, cached in the temp dir) and embedded as cid:, because the Gmail apps force-invert colours in dark mode but never recolour images; without GD it falls back to an HTML header with the embedded, resized logo. `color-scheme: only light|only dark` keeps Apple Mail/Outlook from re-colouring. `emailSend()` attaches the header and sends; `emailSafeFirstName()` and `emailConfirmationAllowed()` (3 per recipient per day) guard confirmations sent to addresses typed into public forms, which never repeat visitor-written text.
- `Ats.php` (requires `Mailer.php`, `Gemini.php`, `EmailTemplate.php`; callers load `config.php`):
  - Columns come from `JobSchema.php` (`jobSchemaEnsure()`).
  - `atsScreenApplicant()` auto-rejects a job application (not a general one) whose result recommends `reject` while still `new`: status `rejected` + `auto_rejected_at`; the HR email notes it. `atsSendPendingRejections()` (daily cron) emails `atsSendRejection()` to rows still rejected an hour later and stamps `decision_emailed_at`; changing the status first cancels it.
  - `atsSendInterviewInvite()` emails the schedule, office (`atsOfficeRows()`: `siteContactAddress()` + contacts) and what to bring.
  - Resume handling: `atsResumeFile()` resolves a stored path and rejects anything outside `uploads/resumes`; `atsExtractText()` does pure-PHP best-effort extraction for txt, rtf, docx (zip XML), legacy doc, and pdf (inflate, ToUnicode cmaps, content-stream text). It never throws and caps output at 60k chars. Images yield no text.
  - Scoring: `atsJobContext()` reads the linked `job_openings` row or a general enterprise profile (`atsEnterpriseProfile()`). `atsKeywordScore()` scores out of 100: keyword coverage 50, years of experience 20, title terms 15, education 10, completeness 5. `atsAiScore()` sends job, form, and the resume (PDF inline ≤ 10 MB, otherwise text) to Gemini with a score/summary/strengths/gaps/recommendation schema.
  - Config: `atsThreshold()` (`ATS_THRESHOLD`, default 70), `atsRecommendation()`, and `atsHrEmail()` (`HR_EMAIL`, with a built-in fallback address).
  - Output: `atsDetails()` decodes the stored `ats_summary` JSON. `atsNotifyHr()` emails HR every application in the applicant's enterprise theme (score badge, summary, strengths/gaps, cover note, resume attached, Reply-To the candidate; works without a score). `atsNotifyUnscored()` covers scoring failures. `atsEsc()`/`atsListHtml()` are HTML helpers.

## Flow

1. `atsScreenSafely($pdo, $id, $notify = true)` wraps `atsScreenApplicant()` and never throws. It loads the applicant, builds the job context, and extracts resume text. It always computes the keyword score. When `ATS_USE_AI=1` and Gemini is enabled, it tries the AI score, which takes precedence and keeps the keyword data.
2. It persists `ats_score`, `ats_summary` (full JSON), `ats_method`, `ats_shortlisted`, and `ats_scored_at`. If `ats_notified_at` is empty and `$notify` is true (every new application; admin re-screen passes false), it calls `atsNotifyHr()` and stamps `ats_notified_at` on success.
3. Mail callers render with `emailRender()` and send with `emailSend()` (header image + their attachments → `Mailer::send()`). SMTP failures are logged and fall back to `mail()`.

## Integration

- `EmailTemplate`/`Mailer`: `api/inquire.php` (team + confirmation), `api/applicants.php` (confirmation), `Ats.php` (HR application email), `api/chat/message.php` (handoff), `api/admin/auth.php` (password code); `api/cron/selftest.php` uses `Mailer` directly.
- `Gemini`: `api/chat/message.php` (chat assistant) and `Ats.php` (optional AI scoring).
- `Ats`: `api/applicants.php` (post-response screening via a shutdown function), `api/admin/applicants.php` (`atsDetails`, re-screen, interview invite), and `api/cron/ats-digest.php` (backfill, retry of undelivered HR emails, pending rejection emails).
- `JobSchema`: `jobSchemaEnsure()` from `api/careers.php` (only after a missing-column error), `api/admin/careers.php`, `api/applicants.php`, `api/admin/applicants.php`, `api/cron/ats-digest.php` and `Ats`.
- `Validation`: `api/inquire.php` and `api/applicants.php` (field rules mirrored by `src/lib/formValidation.ts`).
- `IndexNow`: `api/cron/drive-sync.php` (after every successful sync, only when listings changed).
- Environment: `SMTP_*`/`MAIL_*`, `GEMINI_API_KEY`, `GEMINI_MODEL`, `ATS_THRESHOLD`, `ATS_USE_AI`, `HR_EMAIL`.
