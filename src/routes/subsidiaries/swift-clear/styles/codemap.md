# swift-clear/styles/
## Responsibility
- Holds the SwiftClear stylesheet entry and supporting theme layers.
- `index.css` composes `fonts.css`, `tailwind.css`, and `theme.css`.
- `theme.css` defines semantic colors, radii, base typography, and dark-mode token overrides.
- `fonts.css` imports Righteous/Roboto/Source Code Pro; `tailwind.css` imports Tailwind (`source(none)`) and `tw-animate-css`.
- `globals.css` is empty and not imported by the entry.
## Design
- Base semantic tokens are neutral; SwiftClear pages apply their blue brand palette in utilities.
- Unlike the Luxe Prime and Dynamic Tree themes, tokens sit on plain `:root` with no active-class scoping.
- `@theme inline` maps semantic CSS variables to Tailwind color and radius names.
- Base heading, label, button, and input typography is declared in `@layer base`.
- Component visuals primarily use Tailwind classes and inline theme colors.
## Flow
- `SwiftClear.jsx` does not import this folder, so it is unused in production.
- Only the orphan standalone `main.tsx` imports `styles/index.css`, and nothing references `main.tsx`.
- SwiftClear utilities are instead generated by the corporate `src/styles/global.css` Tailwind build.
- If imported as-is, the unscoped `:root` tokens would leak onto other pages.
- CSS contributes no route or page state logic.
## Integration
- Vite and Tailwind would process these directives only if an imported module referenced them.
- `swiftclear-active` (toggled by the wrapper) is used by `EnterpriseChatbot.css`, not by this theme.
- Font rules and base resets would load through the entry stylesheet.
- This theme is maintained locally and is not shared with sibling subsidiaries.
- Common stylesheet entry is `swift-clear/styles/index.css`.
