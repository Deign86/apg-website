# src/components/

## Responsibility
Shared site chrome and cross-cutting components: enterprise-specific `EnterpriseShell` chrome, the shared AI/live chatbot, per-page SEO metadata (`Seo.tsx`), the cookie-consent banner, and the legacy `Layout`/`Header`/`Footer` set.

## Design
- `EnterpriseShell` is the shared subsidiary layout: `EnterpriseNavProvider` wraps `EnterpriseHeader`, routed `<Outlet />`, `EnterpriseFooter`, and `EnterpriseChatbot`.
- `EnterpriseHeader`/`EnterpriseFooter` resolve tenant branding and content through `getEnterpriseConfig(pathname)` and both navigate through `useEnterpriseNav().navigate(key)`; when it returns `false` (no enterprise page mounted, e.g. `/subsidiaries/<slug>/inquire`) they router-navigate to `/subsidiaries/<slug>` and the pending key is applied when that page registers. Header's parent badge links to `MAIN_SITE_HREF`; its menu toggle is a real `<button>` with `aria-expanded`/`aria-controls`, Escape closes the menu, and active items get `aria-current="page"`.
- `Seo.tsx` is the single source of head metadata. Default `Seo({ title, description, path, enterprise?, image?, noindex?, jsonLd? })` renders title, description, absolute canonical (or `robots noindex, follow`), Open Graph, Twitter card, and one `@graph` JSON-LD block. Canonicals use the apex origin, or the enterprise subdomain origin (`enterpriseOrigin(slug)`) when `enterprise` is set, so they are identical whether reached by apex path or subdomain. `EnterpriseSeo({ slug, page })` looks up per-enterprise meta (title, description, logo, schema type, routed sub-pages); sub-pages without their own URL canonicalize to the enterprise home. Exports `ORGANIZATION_JSONLD` (with `subOrganization` per enterprise) and `WEBSITE_JSONLD`.
- `CookieConsent` stores `{ choice, at }` under a fixed `localStorage` key; reads/writes are wrapped in `try/catch` (blocked storage shows the banner and still honours the choice for the page view). It renders a `role="dialog"` banner with Accept All / Decline and a dismiss button (dismiss = decline), linking to `/privacy`.
- `EnterpriseChatbot` has internally controlled open/input/session/status state; it resolves title/accent/prompts/slug from enterprise config, restores a saved token, starts/polls sessions via `@/lib/ai`, supports explicit live-agent handoff, resets chats, and creates downloadable `jspdf` transcripts. Replies come from the server (`/api/chat/message.php`, Gemini-backed and grounded in a knowledge base, with FAQ fallback). It portals into `document.body`; `EnterpriseChatbot.css` hides `.luxe-chatbot-wrapper` while `html[data-modal-open]` is set by `useModalDialog`.
- Legacy: `Layout` composes `Header`, `<Outlet />`, `Footer`, and `Chatbot` (a thin alias for `EnterpriseChatbot`). `Header` switches APG vs Construction/88Prime hash-link sets by path and links its parent badge to `MAIN_SITE_HREF`; `Footer` returns `null` for `/subsidiaries/88prime`.

## Flow
- `EnterpriseShell` resets scroll and refreshes AOS on pathname change, then installs the nav provider so child enterprise views and header/footer share current page/navigation state.
- `EnterpriseChatbot` maps path to config/slug → restores or starts a session → maps server messages to display messages → polls `poll.php` by last message id (3s open, 5s closed/hidden) and reconciles optimistic visitor messages one-for-one → after a send, fetches the persisted bot reply via an immediate poll instead of appending `res.reply`. Unread admin messages increment a badge while closed.
- Route pages and shells render `<Seo>`/`<EnterpriseSeo>`; Helmet merges the tags into `<head>`.

## Integration
- **Consumers/routes:** `src/App.jsx` uses `EnterpriseShell` for Realty, Luxe Prime, Dynamic Tree, SwiftClear, Construction, and 88Prime routes and lazy-loads `CookieConsent`; `Layout` is imported by `App.jsx` but not routed (so `Header`/`Footer`/`Chatbot` are effectively unused). `AlphaAssistant` (redesign) wraps `EnterpriseChatbot`. `Seo` is used by `RedesignShell`, `Contact`, `Properties`, `NotFound`, `PrivacyPolicy`, `TermsConditions`; `EnterpriseSeo` by `VirtualOffice` and every subsidiary page plus `EnterpriseInquire`.
- **Dependencies:** `src/context/EnterpriseNavContext`; `src/data/enterpriseConfig` (`getEnterpriseConfig`, `DEFAULT_ENTERPRISE_CONFIG`); `src/data/enterprises` (`ENTERPRISES` names for JSON-LD); `src/lib/enterpriseHost` (`MAIN_SITE_HREF`, `ROOT_DOMAIN`, `enterpriseOrigin`); `@/lib/ai`; React Router; `react-helmet-async`; AOS; `jspdf`; `lucide-react`; component CSS files.
